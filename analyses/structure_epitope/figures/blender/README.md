Renderer: **Blender (GPL-3) + Molecular Nodes (GPL-3)** — both permit commercial use, licence-clean
(ChimeraX is excluded). This session produced the inputs; a human operator does the one-time template
setup; the rest renders headlessly and tiles into a grid.

## Step 1 — reusable template (`template.blend`) — ALREADY BUILT
`template.blend` is pre-generated by `build_template.py` (verified on **Blender 5.0.1 + Molecular Nodes**;
preview in `template_preview.png`): TREM2 **Surface coloured by epitope** (apical contact residues orange,
rest grey) and **semi-transparent** so the binder shows through — via a per-atom `Color` attribute — plus a
human-green **Cartoon** binder, camera + 3-point area lights + transparent film. Toggle `COLOUR_BY_EPITOPE`
/ `TARGET_ALPHA` at the top of `build_template.py` for a neutral opaque-grey target (Fig 10 gallery tiles).
**Open it and refine** — apical camera angle, region colours/opacity (edit the `Color` attribute or the
knobs) — then lock the camera. Regenerate any time: `blender --background --python build_template.py`. The
manual recipe below documents what it contains and how to change it:
1. Import `pdbs/design_017.pdb` via Molecular Nodes.
2. Style it: **chain A (target)** as a surface or cartoon in neutral grey; **chain B (binder)** as
   cartoon in a cohort colour (human `#1FE48F`, agent `#30C5F5`). Molecular Nodes can split by
   `chain_id` — set two Style nodes gated on chain A vs B.
3. Add a camera, a 3-point / studio light setup, and a transparent-film world (Render Properties →
   Film → Transparent) so panels composite cleanly. Frame TREM2; **do not move the camera again** —
   the common frame depends on it.
4. Save as `template.blend` in this folder. Note the exact names of (i) the imported MN object and
   (ii) the two chain materials — you'll pass them to the render script or hard-code them there.

## Step 2 — headless render of the rest
`render_headless.py` is a skeleton to adapt to your Molecular Nodes version (its Python API changes
between releases — align the `import`/load calls to what your `template.blend` uses). Then:
```bash
# one design
blender --background template.blend --python render_headless.py -- \
    --pdb pdbs/design_013.pdb --out renders/design_013.png --binder-color agent
# batch (all of a list)
for d in 017 013 074 132 102 034; do
  blender --background template.blend --python render_headless.py -- \
    --pdb pdbs/design_${d}.pdb --out renders/design_${d}.png
done
```

## Step 3 — tile into the grid
Pure-Python, no Blender:
```bash
uv run python make_grid.py --renders renders --designs 017 013 074 132 102 034 \
    --cols 3 --out ../fig10_gallery.png
```
`make_grid.py` labels each tile from `manifest.csv` (name, Kd, cohort).
