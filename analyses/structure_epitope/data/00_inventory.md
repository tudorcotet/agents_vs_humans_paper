## 5. Kd censoring audit (the number that sets every affinity n)

- **37 hits** (`is_hit==True`) = 36 `binder` + 1 `weak`.
- **36 have a fitted mean Kd.** The single exception is **design 5** (`5_NovoFy_RFDiffusion_
  LigandMPNN_Boltz`, human, `binding_label=weak`, `n_with_kd=0`). This one design **is** the
  entire gap between "37 binders" and "median-among-fitted" that the manuscript hints at.
- **No interval / bound censoring exists.** The replicate table stores `kd_M` as float; there are
  **no "＞X µM" strings, no inequality bounds, no unfittable-but-counted rows.** Non-binders and
  non-expressers simply have null Kd. Verified by scanning every object column of
  `bli_replicates.csv` for `> < µ unfit` markers — none in the KD fields.
- **Every one of the 36 fitted Kd is backed by ≥2 replicate fits** (30 designs have 2, 6 have 3).
  **Zero single-replicate Kd.** So there is no "single-replicate estimate" subclass to worry about.
- **Median among fitted = 91.85 nM** (n=36) → **exactly the manuscript's number.** Split: human
  91.85 nM (n=24), agent 109.36 nM (n=12) → **both match the manuscript exactly.**
- **Range: 1.11 nM (design 17, MRAZS/Mosaic) to 1,634.8 nM (design 62, crow).** (Note the brief's
  stated upper bound "1,387 nM" is design 123/GLM-5's best, not the global max — see §7.)
- **Quality flags (not censoring, but worth carrying):** `weird_replicates_flag` is False for all
  36. `assay_methods_mixed` True for 4 (designs 134, 22, 87, 63 — SPR/BLI disagreed).
  Replicate CV > 50% for 3 (designs 103, 22, 11). These are recorded in `kd_quality_flag` in the
  canonical table so any affinity analysis can optionally down-weight or sensitivity-test them.

**Conclusion:** `P_kd = 36` clean point estimates. **The rescoping trigger (P_kd < 30) is not
met.** The affinity analysis (deliverable 2) proceeds at n=36 (or n=35 after any additional
weak-binder exclusion, at your discretion).

   **"10 human teams"**; the Participation section says **"9 human teams … 81 designs."** The data

   section, but part of the reconciliation).
2. **Best-Kd range mis-stated in the handoff brief**, not the manuscript: the brief's "1.11 nM –

3. **Design-Method Breakdown table mixes denominators** (already flagged in brief §1.5 / line 58):

## 8. TREM2 numbering convention (pinned now, used everywhere)

Shipped Boltz-2 complex CIFs: **chain A = TREM2 target (175 residues, authored 1..175)**,
**chain B = binder**. Chain A is the **full BLI construct**: Met + UniProt Q9NZC2 residues 19–174
+ `GGGSGGGS` linker + 10×His.

- **Map:** `UniProt_resnum = construct_pos + 17`. Verified against landmarks: construct pos 27 = W
  = **UniProt W44** (hydrophobic tip); construct pos 19 = C = **UniProt C36** (canonical disulfide).
- IgSF domain (19–132) = construct pos **2–115**.
- **Stalk (133–174) = construct pos 116–157 — present in every folded complex.** The
  stalk-violation analysis (designs contacting the region they were told to avoid) is therefore
  **fully feasible** from the shipped structures.
- Linker = 158–165; His-tag = 166–175 (exclude from interface analysis).

Recorded in `canonical_schema.json → trem2_numbering`.
